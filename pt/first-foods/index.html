Introdução alimentar com o OBubba

Cada primeiro alimento, registrado e lembrado.

O OBubba acompanha os alimentos que seu bebê já provou, sinaliza alérgenos automaticamente e ajuda a introduzir os novos com calma. Grátis para baixar.

Baixar para iPhoneBaixar para Android

O OBubba oferece informações gerais com base nas orientações do Reino Unido. Não é aconselhamento médico e não faz diagnósticos. Cada bebê é único. Se o seu bebê tem alguma alergia conhecida, eczema grave ou alguma condição de saúde, converse com o pediatra antes de começar a introdução alimentar. Aprenda primeiros socorros para bebês e, em uma emergência, ligue para o número de emergência local (192, SAMU, no Brasil).
